# A-tatis · El bosque de las cartas — APK

Aplicación Android en pantalla completa que empaqueta la publicación activa de ChatGPT Pages:

https://a-tatis-bosque-cartas.emp33.chatgpt.site

## Características
- Orientación horizontal fija.
- WebView Android con JavaScript, DOM Storage, cookies y aceleración por hardware.
- Pantalla completa inmersiva.
- Mantiene la misma versión publicada del juego y sus actualizaciones del sitio.
- Ícono de launcher con la carita del capibara.
- Menú inicial centrado automáticamente en la vista Android.
- Requiere conexión a Internet para cargar el contenido publicado.
