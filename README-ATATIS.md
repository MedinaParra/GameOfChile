# A-tatis

Prototipo jugable Android 3D de mundo abierto protagonizado por un capibara que explora un bosque y recoge manzanas.

## Controles
- Joystick táctil izquierdo: caminar.
- Arrastre táctil derecho: girar la cámara.
- Objetivo: recoger 20 manzanas.

## Contenido
- Capibara 3D generado proceduralmente.
- Bosque abierto con árboles, rocas, flores y caminos.
- Lago y puente.
- Manzanas coleccionables que reaparecen.
- Pantalla de victoria.

El APK se genera automáticamente mediante GitHub Actions y se publica como artefacto `A-tatis-APK`.
