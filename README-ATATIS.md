# A-tatis

Juego Android 3D de mundo abierto protagonizado por un capibara que explora un bosque y recoge manzanas.

## Rama
`atatis-openworld-3d`

## Controles
- Joystick táctil izquierdo: caminar.
- Arrastre táctil derecho: girar la cámara.
- Objetivo: recoger 20 manzanas.

El proyecto Android completo está empaquetado en `A-tatis-source.zip.b64`. El workflow de GitHub Actions lo reconstruye y genera el APK `A-tatis.apk`.
